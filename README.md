# Parafia Demo K1

Demo szablonu strony parafialnej dla polskich parafii.

**Live URL:** https://nooti-lab.github.io/parafie-demo-k1/

## Wersja / Redesign

**v2 (październik 2026)** — Gruntowny redesign wizualny:

- **Hero section** — pełnoekranowy nagłówek z ikoną kościoła i harmonogramem Mszy
- **Sticky navigation** — kompaktowa nawigacja z hamburger menu na mobile
- **Typografia** — fonty Lora (serif) + Inter (sans-serif) z Google Fonts
- **Tabele** — czytelniejsza tabela intencji mszalnych z kolorowaniem wierszy
- **Karty wspólnot** — wizualne karty z ikonami i animacjami hover
- **Sekcja kontaktowa** — grid z ikonami i wyraźnym CTA
- **Dostępność** — focus states, ARIA labels, print-friendly CSS
- **Mobile-first** — przetestowane na 375px (iPhone SE)

## Cena wdrożenia

**1990 zł netto** — kompletna strona parafii z treściami klienta.

## Struktura

Wszystkie 8 sekcji z zakotwiczeniami:
- `#home` — Strona główna / Hero
- `#ogloszenia` — Ogłoszenia parafialne
- `#intencje` — Intencje mszalne
- `#sakramenty` — Sakramenty
- `#nabozenstwa` — Nabożeństwa / godziny
- `#o-parafii` — O parafii
- `#wspolnoty` — Wspólnoty / grupy
- `#kontakt` — Kontakt / kancelaria

## Uwagi

To jest strona **DEMO** — nie jest stroną prawdziwej parafii. Dane kontaktowe i treści są fikcyjne.
